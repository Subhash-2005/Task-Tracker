# Task Tracker CI/CD Project

A full-stack task tracker application built to learn:

- GitHub Actions
- CI/CD pipelines
- Vercel deployment
- Render deployment
- Pull request workflow
- Environment variables

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Node.js
- Express

## Features

- Add tasks
- Delete tasks
- Live deployment
- CI pipeline
- Pull request validation
